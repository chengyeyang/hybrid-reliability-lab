# GitHub Related Operations

---

## 1. Create a new GitHub repository
1. Go to GitHub main page
2. Click `Repositories` tab
3. Click the green `New` button on the right side
4. In the new page
   * Fill out Repository name and Description(optional)
   * Select the configuration you want
5. Click the green `Create repository` button in the bottom
