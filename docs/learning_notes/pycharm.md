# PyCharm Related Operations

---

## 1. Set up the virtual environment for projects
1. Add a new folder for the project
2. In Pycharm, `File` -> `Open` -> select the folder added in step 1
3. Click to `Python Interpreter` in the bottom-right -> `Add Interpreter` -> `New Virtual Environment` -> Select the Python version you want to use.
4. In PyCharm terminal, enter `where python`, and if you see something like `...\you_project_name\.venv\Scripts\python`, that means you have succeeded.
